# Court Process Simulator: interactive prototype v0.1

Open `index.html` in a modern browser, or run `python -m http.server 8000` from this directory and open http://localhost:8000.

This is a functional **client-side educational prototype**. It includes role selection, constrained stage transitions, interactive actions, fictional exhibits, session transcript, localStorage persistence, and JSON export.

**Important limitations:** no AI API, server-side security, authentication, real court/legal authority, authoritative deadline calculation, verified rulings, backend database, or public deployment. Client-side permissions illustrate behavior only, and must not be trusted to secure real user data. Role changes intentionally create a new session. This is not legal advice.

The existing website ZIP at repository root is left untouched. A production integration should first inspect/extract that original source, then migrate this prototype into its stack.
